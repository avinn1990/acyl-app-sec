# Scan goals

## OS command injection
CWE: CWE-78
id: cwe-78-command-injection

Locate improper neutralization of special elements used in an OS command
(OS command injection). Focus on Python handlers that build shell commands
from request or user input.

## Hardcoded credentials
CWE: CWE-798
id: cwe-798-hardcoded-credentials

Find hard-coded credentials and secrets committed into source.
